Finding the **Likely Reason** (Root Cause) of cart abandonment is handled by the **Root Cause Reasoning Agent** in [`cart_abandonment_ml/reasoning/root_cause_agent.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/reasoning/root_cause_agent.py).

The system diagnoses **WHY** a shopper is hesitating or leaving by classifying their session into **1 of 10 standard root cause categories**.

---

## 📑 1. The 10 Allowed Root Cause Taxonomy

| Root Cause Category | Key Indicators & Triggers |
| :--- | :--- |
| **Price Sensitive** | High price sensitivity score, competitor tab switching, copy-pasting product titles, high cart total. |
| **Delivery Concern** | High unexpected shipping charges, long estimated delivery time, location tier friction. |
| **Quality Uncertainty** | Frequent zoom on product images, reading 1-star reviews, checking return/warranty policy. |
| **Trust Issues** | Low seller trust rating, low delivery confidence index, unverified seller warning. |
| **Payment Friction** | OTP timeout, repeated payment gateway retries, failed transaction attempt. |
| **Window Shopping** | Multiple tab switches, long idle time without adding items, high page view count with zero checkout steps. |
| **Product Availability** | Out-of-stock items in cart, delivery unserviceable for pincode. |
| **Technical Problem** | Page load latency spikes, app crash recovery, slow network flag. |
| **Gift Purchase** | Gift wrap requested, different shipping address from billing address. |
| **Low Purchase Intent** | Impulse cart add, low session duration, zero historical purchases. |

## ⚙️ 2. How the Diagnosis Works (Two-Engine System)

```mermaid
flowchart TD
    A[Session Signals + XGBoost Probability + SHAP Drivers] --> B{Gemini LLM Available?}
    B -->|Yes| C[Generative LLM Reasoning Prompt]
    B -->|No / Fallback| D[Heuristic SHAP Feature Keyword Matching]
    C --> E[Structured JSON Root Cause Result]
    D --> E
```

### Engine A: Generative AI Reasoning (Google Gemini LLM)
When the Gemini API key is configured, the agent passes a structured prompt containing:
1. **XGBoost Prediction Risk**: Model output (e.g. `84.2% High Risk`).
2. **Top 15 SHAP Attribution Signals**: Feature impact ranked by magnitude with directional indicators (e.g. `total_shipping_charges: +0.341 ▲ increases risk`).
3. **Session Telemetry & Metadata**: Hesitation score, cart total, tab switch count, user persona.

The Gemini model runs zero-shot reasoning constrained by a strict system prompt and returns structured JSON.

---

### Engine B: Heuristic Fallback Engine (Rule-based)
If Gemini is offline, network-throttled, or missing an API key, the system uses a **keyword-weighted heuristic fallback**:

```python
# Feature Keyword Mapping (Fallback Engine)
keyword_map = [
    (["price_sensitivity", "competitor", "discount"], "Price Sensitive"),
    (["shipping", "delivery", "estimated_delivery"], "Delivery Concern"),
    (["quality_uncertainty", "negative_reviews"],    "Quality Uncertainty"),
    (["trust_score", "seller_trust", "fake_review"], "Trust Issues"),
    (["payment_failure", "otp_timeout"],             "Payment Friction"),
    (["tab_switch", "window_shopper"],               "Window Shopping"),
    (["delivery_unavailable", "out_of_stock"],       "Product Availability"),
]
```
The fallback agent scans the top positive SHAP drivers to find the highest-ranking feature match and assigns the corresponding root cause.
