In this project, the **models** form a multi-layered, hybrid AI system that combines **predictive machine learning**, **explainable AI**, **vector retrieval (RAG)**, and **generative AI (LLMs)**.

## 🤖 1. Machine Learning Predictive Models

### 1.1 XGBoost Classifier (`classifier.json` / `classifier.pkl`)
* **Location**: [`cart_abandonment_ml/training/train.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/training/train.py) & saved in [`models/classifier.json`](file:///c:/Users/Meet/Downloads/new%20flip/models/classifier.json)
* **Model Type**: Gradient Boosted Decision Tree (GBDT) Binary Classifier (`xgb.XGBClassifier`)
* **Input**: 128+ continuous and categorical session signals (e.g., cart value, shipping fee, idle time, tab switches, price sensitivity, past return rate).
* **Target Output**: $P(\text{Abandon} \mid X) \in [0.0, 1.0]$ (Binary classification: `1` = Abandon, `0` = Retained).
* **What It Does**: It is the **primary real-time prediction engine**. When a shopper browses or adds items to their cart, this model evaluates their session telemetry in milliseconds to estimate the exact probability that the user will abandon their shopping cart.

### 1.2 XGBoost Regressor (`regressor.json` / `regressor.pkl`)
* **Location**: [`cart_abandonment_ml/training/train.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/training/train.py) & saved in [`models/regressor.json`](file:///c:/Users/Meet/Downloads/new%20flip/models/regressor.json)
* **Model Type**: Gradient Boosted Decision Tree Regressor (`xgb.XGBRegressor`)
* **Target Output**: Continuous abandonment risk score / continuous recovery expectation.
* **What It Does**: Used for continuous price sensitivity calibration, research validation, and continuous risk scoring benchmarks alongside the classifier.

## 🔍 2. Explainable AI Model

### SHAP Explainability Engine (`ShapEngine`)
* **Location**: [`cart_abandonment_ml/explainability/shap_engine.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/explainability/shap_engine.py)
* **Model Type**: Game-theoretic feature attribution using `shap.TreeExplainer`
* **What It Does**: Explains **WHY** the XGBoost classifier predicted a high abandonment risk for a specific user session.
  * Calculates exact **Shapley values** ($\phi_i$) for every input feature.
  * Identifies the **Top 5 positive pushers** (factors increasing abandonment risk, e.g., `total_shipping_charges`, `competitor_price_checked`) and **negative pullers** (factors reducing risk, e.g., `is_plus_member`, `high_rating`).
  * Provides transparent feature importance directions (`"increases risk"` vs. `"decreases risk"`).

In this project, **Cart Abandonment Prediction** works through a step-by-step machine learning pipeline. 

Here is the step-by-step breakdown of how a user's shopping session is captured, processed, and evaluated:

---

## 🔄 End-to-End Prediction Pipeline

```mermaid
flowchart TD
    A[1. Live User Session Telemetry] --> B[2. Preprocessing & Feature Alignment]
    B --> C[3. StandardScaler Transformation]
    C --> D[4. XGBoost Classifier Tree Ensemble]
    D --> E[5. Sigmoid Probability Output P]
    E --> F{6. P >= 0.50 Threshold Check}
    F -->|Yes| G[Prediction: Likely Abandon]
    F -->|No| H[Prediction: Likely Purchase]
    E --> I[7. SHAP Feature Attribution]
    I --> J[Top 5 Friction Drivers]
```

## 🛠️ Step-by-step Technical Breakdown

### Step 1: Live Session Telemetry Capture (Input Features)
When a user interacts with the e-commerce store, the system collects real-time behavioral signals across 128+ features:
* **Cart & Price Telemetry**: `cart_value`, `total_shipping_charges`, `total_items_in_cart`, `discount_percentage`.
* **Behavioral & Micro-gestures**: `hesitation_score`, `tab_switch_count`, `idle_time_seconds`, `competitor_price_checked`.
* **Trust & User Context**: `trust_score`, `account_age_days`, `historical_return_rate`, `persona` (*Price Sensitive*, *Quality Conscious*, etc.).

---

### Step 2: Feature Alignment & Preprocessing
* **Implementation**: [`cart_abandonment_ml/preprocessing/preprocessing.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/preprocessing/preprocessing.py) & [`cart_abandonment_ml/training/predict.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/training/predict.py)
* **Alignment**: The incoming JSON request dictionary is aligned to the expected 128-dimensional feature vector. Missing fields are automatically imputed (numeric fields set to mean/median, missing categorical fields encoded).
* **Scaling**: Continuous features are normalized using the pre-trained `StandardScaler` artifact:
  $$Z = \frac{X - \mu}{\sigma}$$

---

### Step 3: XGBoost Model Inferences & Sigmoid Calculation
* **Implementation**: [`cart_abandonment_ml/training/train.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/training/train.py) & `models/classifier.json`
* **Tree Ensemble Evaluation**: The preprocessed feature vector $\mathbf{x}$ is passed into the trained **XGBoost Classifier**. 
* The model sums the leaf outputs across all $K$ decision trees:
  $$\hat{y}_{\text{raw}} = \sum_{k=1}^{K} f_k(\mathbf{x})$$
* **Sigmoid Activation**: Converts raw tree logits into a probability $P \in [0.0, 1.0]$:
  $$P(\text{Abandon} \mid \mathbf{x}) = \frac{1}{1 + e^{-\hat{y}_{\text{raw}}}}$$

---

### Step 4: Decision Boundary & Classification Threshold
* If $P(\text{Abandon}) \ge 0.50$, the system flags the session as **`prediction = True`** (`"Likely Abandon"`).
* If $P(\text{Abandon}) < 0.50$, the session is flagged as **`prediction = False`** (`"Likely Purchase"`).

---

### Step 5: SHAP Feature Attribution (Explaining *Why*)
* **Implementation**: [`cart_abandonment_ml/explainability/shap_engine.py`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/explainability/shap_engine.py)
* Using `shap.TreeExplainer`, the system calculates Shapley values ($\phi_i$) for each feature to see how much each signal increased or decreased abandonment risk:
  $$P(\text{Abandon}) = \text{Base Value} + \sum_{i=1}^{M} \phi_i$$
* **Output**: Retrieves top friction drivers (e.g., `total_shipping_charges: +0.341 (increases risk)`, `is_plus_member: -0.120 (decreases risk)`).

## 💻 Python Code Example (Predictor Execution)

Here is how prediction is run in Python using [`Predictor`](file:///c:/Users/Meet/Downloads/new%20flip/cart_abandonment_ml/training/predict.py#L40-L42):

```python
from cart_abandonment_ml.training.predict import Predictor

# 1. Instantiate predictor (loads scaler and XGBoost classifier)
predictor = Predictor()

# 2. Input session telemetry
session_data = {
    "persona": "Price Sensitive Shopper",
    "hesitation_score": 3.2,
    "trust_score": 0.45,
    "total_shipping_charges": 75.0,
    "cart_value": 3499.0,
    "tab_switch_count": 7,
    "session_duration_seconds": 240
}

# 3. Predict abandonment
result = predictor.predict(session_data, top_n_features=5)

print(f"Abandonment Probability: {result.abandonment_probability:.2%}")
print(f"Prediction: {result.predicted_class}")
print("Top Drivers:", [(f.feature, f.shap_value) for f in result.top_features])
```
